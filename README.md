# GridCraft — เว็บแอปจัดเรียงรูปภาพ Grid Collage

เว็บแอปพลิเคชันสำหรับรวมและจัดเรียงรูปภาพแบบ **Grid Collage** (สไตล์ Instagram Layouts) ที่ทำงานบนเว็บเบราว์เซอร์ได้ทันทีโดยไม่ต้องพึ่งพา Backend Server โค้ดทั้งหมดรวมอยู่ในไฟล์ `index.html` ไฟล์เดียว (HTML5 Canvas + Tailwind CSS + Vanilla JavaScript)

---

## ความสามารถหลัก (Features)

- **เทมเพลต Grid หลากหลาย (2–6 รูป)**
  - **2 รูป**: แบ่งครึ่งซ้าย-ขวา (`1x2`), แบ่งครึ่งบน-ล่าง (`2x1`)
  - **3 รูป**: 3 คอลัมน์, ซ้ายใหญ่ 1 + ขวาย่อย 2, บนใหญ่ 1 + ล่างย่อย 2
  - **4 รูป**: ตาราง `2x2`, ซ้ายใหญ่ 1 + ขวาย่อย 3
  - **5 รูป**: บน 2 + ล่าง 3, ซ้ายใหญ่ 1 + ขวา 4
  - **6 รูป**: ตาราง `2x3` และ `3x2`
- **สัดส่วนภาพและกรอบ (Aspect Ratio & Border)**
  - รองรับสัดส่วน `1:1` (IG Post), `4:5` (IG Portrait), `9:16` (Story / Reels) และ `16:9` (Desktop / Banner)
  - ปรับความหนาช่องไฟ/ขอบ (`0px – 40px`) และความโค้งมนของมุม (`0px – 30px`)
  - เลือกสีพื้นหลัง/สีขอบได้ทั้งจากชุดสีด่วนและ Color Picker อิสระ
- **จัดการรูปภาพในแต่ละช่องแบบ Interactive**
  - คลิกช่องว่างเพื่อเลือกรูป, ลากไฟล์มาวาง (Drag & Drop) ลงช่องโดยตรง หรือใช้ปุ่ม **อัปโหลดหลายรูป** เพื่อเติมลงช่องอัตโนมัติ
  - ลากรูปภายในช่องเพื่อจัดจุดโฟกัส (Pan), ซูมเข้า-ออก (`100% – 300%`) ผ่านสไลเดอร์หรือลูกกลิ้งเมาส์
  - หมุนภาพ `90°`, พลิกซ้าย-ขวา (Flip), สลับตำแหน่งระหว่างช่อง (Swap), เปลี่ยนรูป และลบรูป
- **ส่งออกไฟล์ความละเอียดสูง (High-Resolution Export)**
  - เลือกความละเอียดได้ `1080px` (มาตรฐาน IG) หรือ `2160px` (HD+)
  - บันทึกเป็นไฟล์ **PNG** (ไม่บีบอัด) หรือ **JPG** (ปรับระดับคุณภาพได้ `50% – 100%`)

## วิธีใช้งาน (How to Use)

1. **เลือกเทมเพลต**: ที่แท็บ **เทมเพลต** เลือกจำนวนรูปที่ต้องการ (2–6 รูป) แล้วคลิกเลือกรูปแบบ Grid
2. **เพิ่มรูปภาพ**:
   - คลิกที่ช่องว่างบนแคนวาสเพื่อเลือกรูปทีละช่อง
   - หรือลากไฟล์รูปภาพจากเครื่องมาวางลงบนช่องที่ต้องการ
   - หรือกดปุ่ม **อัปโหลดหลายรูป** ด้านบนขวาเพื่อเลือกหลายภาพพร้อมกันให้ลงช่องอัตโนมัติ
3. **ปรับแต่งสัดส่วนและกรอบ**: ที่แท็บ **สัดส่วน/ขอบ** เลือก Aspect Ratio, ช่องไฟ, ความโค้งมนของมุม และสีพื้นหลัง
4. **จัดตำแหน่งรูปในช่อง**: คลิกเลือกรูปบนแคนวาสเพื่อลากจัดตำแหน่ง (Pan), ใช้ลูกกลิ้งเมาส์หรือแท็บ **ปรับแต่งรูป** เพื่อซูม หมุน พลิก หรือสลับช่องกับรูปอื่น
5. **บันทึกภาพ**: ไปที่แท็บ **ส่งออก** เลือกความละเอียด (`1080px` หรือ `2160px`) แล้วกด **บันทึกเป็น PNG** หรือ **บันทึกเป็น JPG**

## วิธีการนำไปใช้และติดตั้ง (Deployment)

### 1. เปิดใช้งานทันทีบนเครื่อง (Local)
ไม่จำเป็นต้องติดตั้ง Node.js หรือ Dependency ใดๆ:
1. ดาวน์โหลดหรือ Clone โปรเจกต์นี้
   ```bash
   git clone git@github.com:nisshin61/grid-collage.git
   ```
2. ดับเบิลคลิกเปิดไฟล์ `index.html` ด้วยเว็บเบราว์เซอร์ (Chrome, Safari, Edge, Firefox) เพื่อใช้งานได้ทันที

### 2. รันผ่าน Local Web Server (ทางเลือก)
หากต้องการเปิดผ่าน `http://localhost` สามารถใช้คำสั่งใดคำสั่งหนึ่งต่อไปนี้ในโฟลเดอร์โปรเจกต์:
```bash
# ด้วย Python
python3 -m http.server 8080

# หรือด้วย Node.js
npx serve .
```
จากนั้นเปิดเบราว์เซอร์ไปที่ `http://localhost:8080`

### 3. เผยแพร่ออนไลน์ฟรีด้วย GitHub Pages
เนื่องจากเป็น Static Web App ไฟล์เดียว จึงสามารถโฮสต์บน GitHub Pages ได้ทันที:
1. เข้าไปที่ Repository บน GitHub (`nisshin61/grid-collage`)
2. ไปที่ **Settings** > **Pages**
3. ในหัวข้อ **Build and deployment** เลือก Source เป็น **Deploy from a branch**
4. เลือก Branch เป็น `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
5. รอสักครู่ GitHub จะสร้าง URL สำหรับเปิดใช้งานออนไลน์ให้โดยอัตโนมัติ
